PURPOSE
-------
Retrieves evidence supporting or contradicting causal relationships.

RESPONSIBILITIES
----------------
- News retrieval
- Evidence ranking
- Contradiction analysis
- Source credibility scoring

INPUT
-----
Causal edge

OUTPUT
------
Supporting evidence objects

TECH STACK
----------
- Tavily
- GDELT
- BM25
- Cross-encoder reranking

FUTURE IMPROVEMENTS
-------------------
- Real-time streaming
- Trust scoring
- Multi-source fusion
