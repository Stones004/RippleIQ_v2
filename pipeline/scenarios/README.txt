PURPOSE
-------
Generates competing future scenarios from current events.

RESPONSIBILITIES
----------------
- Scenario clustering
- Bayesian probability estimation
- Macro outcome generation

INPUT
-----
Historical precedents + graph outputs

OUTPUT
------
Scenario probability distribution

TECH STACK
----------
- PyMC
- HDBSCAN
- XGBoost

FUTURE IMPROVEMENTS
-------------------
- Regime-switching models
- Counterfactual simulation
- Dynamic priors
